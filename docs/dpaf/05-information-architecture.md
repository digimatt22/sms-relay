# Information Architecture

Status: Draft after first discovery interview.

## Operator Dashboard Surfaces
- Queue overview.
- Message detail and delivery attempts.
- Gateway fleet status.
- Gateway health/log detail.
- Basic message insertion or test-send workflow, if approved.
- Settings for gateway API keys, carriers/APNs, retry policy, and lease timeout, if approved for MVP.

## Non-UI Surfaces
- Central API for message insertion, gateway claims, status updates, logs, and health.
- Gateway appliance configuration.
- Deployment and operator runbooks.
