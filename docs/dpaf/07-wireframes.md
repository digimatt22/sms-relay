# Wireframes

Status: Required; draft screen list.

MVP includes a dashboard/operator UI. Low-fidelity wireframes should cover:
- Queue overview.
- Message detail.
- Gateway fleet list.
- Gateway health/log detail.
- Message creation/test-send surface, if approved.
- Gateway/settings management, if approved.

## Low-Fidelity Layout Notes
- Queue overview: filter bar, status counters, dense message table, create-message action.
- Message detail: summary, lifecycle timeline, attempts table, metadata panel, error panel.
- Gateway fleet: gateway table with status, last heartbeat, carrier/SIM/modem fields.
- Gateway detail: health summary, recent attempts, log stream, key management actions.
- Create message: destination, body, priority, scheduled time, customer/account, idempotency key, metadata JSON, callback URL.
